# Nest — budget tracker

## Done
- Accounts: email + password sign-up/sign-in, Google sign-in, display name
- Data: categories, monthly budgets, expenses (each account sees only its own)
- Budget screen with two tabs: Activity (daily log of every spend, grouped by date) and Summary (month by category with tap-to-edit budgets)
- Comparison: per-category change vs prior month + last 4 months of bars
- Insights: overspend warnings, budget rebalancing, savings opportunities, trend spotting — with one-tap apply buttons
- Add / rename / delete categories; add and remove expenses; copy last month's budgets
- Mobile-first layouts; starts empty with an optional starter category set
- Plain language throughout (no "ledger"/"envelopes"/"over cap" jargon); category rows show only the name, no sub-descriptions
